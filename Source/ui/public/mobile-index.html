🔄 Looping Modes
  • Classic Mode: The first layer defines the total loop length.
  • Bars Mode: Length is pre-determined by BPM and Bar settings.
  • Dynamic Mode: Overdubs extend the loop length dynamically until reaching the Global Max Length set in the Settings menu.
🎵 Tempo / Click Track Sample-accurate click track synthesized in the audio thread, routed through your audio interface.
  • BPM / TAP: Enter an exact tempo or tap repeatedly to detect it. TAP changes BPM only and does not enable the click.
  • Click: Enable or disable the metronome during recording and playback from the main screen.
  • Pre-Count: Enable the count-in from the main screen. It works with button, key, MIDI, and footswitch triggers.
  • Rhythm & Bars: Set Bars, Beats, Pre-count Bars, audition the click, and edit accent (A) and regular (B) beats.
🎯 Arm Overdub Queues an overdub to start precisely at the next loop boundary instead of immediately. When armed, the status displays ARMED with a blue indicator. The overdub will automatically engage when the loop restarts, ensuring perfectly timed layers. Enabled by default.
⌨️ Key Bindings Bind any keyboard key to any of the 20 mappable actions from the MIDI / Key Mapping panel. Each action supports one key — assigning a key that is already bound to another action will automatically reassign it (auto-exclusive). Bindings are saved with the plugin state.
💡 Visual Feedback
  • Orange Ring Flash: Undo — the playback ring briefly flashes orange when a layer is removed.
  • Red Ring Flash: Clear — the ring flashes red when the entire loop is cleared.
  • Pulsing State Text: The status label (RECORDING, OVERDUBBING, etc.) pulses to indicate active states.
  • Beat Highlighting: Rhythm matrix cells highlight in sync with the metronome beat.
  • Blue Arm Overdub: When overdub is armed and waiting for the loop boundary, the status shows ARMED with a blue indicator.
🔊 Multi-Layer Architecture Instead of a single buffer with destructive overdub, the looper uses up to 8 independent layers. Each layer is a separate audio recording — overdubs never overwrite previous recordings. Use Undo to remove layers one at a time. The maximum number of layers can be configured in the Settings menu (default: 8).
⚠️ Memory RAM Usage All loop layers are stored in active RAM for zero-latency overdubbing. Longer Max Length settings combined with more layers use more memory.
  • 5 Minutes (8 layers): ~0.9 GB RAM
  • 10 Minutes (8 layers): ~1.8 GB RAM
  • 20 Minutes (8 layers): ~3.7 GB RAM
